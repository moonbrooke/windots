# AHK Scripts

A collection of my AutoHotKey scripts

### keybinds

My custom Windows keybinds.

- `Windows + Enter`: Launch Windows Terminal
- `Windows + Q`: Quit current active window
- `Windows + W`: Launch Microsoft Edge
- `Alt + 1`: Type first email
- `Alt + 2`: Type second email

Emails are not stored in this repo. Create `AHK/keybinds.local.ini` (gitignored):

```ini
[emails]
1=you@example.com
2=other@example.com
```

### zoomy_mouse

A zoom/magnifier tool.

- `F1`: Toggle zoom
- `Shift+F1`: Reset zoom
- `Alt+F1`: Change zoom shape (circle/square)
- `Shift+Scroll`: Zoom in or out
- `Ctrl+Shift+Scroll`: Resize zoom area
